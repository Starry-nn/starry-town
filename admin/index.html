我的私人小镇 →
第一次用？点这里看怎么设置（只需要做一次）
  1. 打开 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 选 Only select repositories，只勾 starry-town。
  3. Permissions → Repository permissions → Contents 设为 Read and write，其他都不用动。
  4. 生成后复制令牌，回到这里点“GitHub 令牌”粘贴进去。

令牌只保存在你这台电脑的这个浏览器里，不会上传到别处；任何没有令牌的人打开这个页面都保存不了。改完点“保存并发布”，一两分钟后线上就会更新。占位符 {n} {a} {b} 请保留。
